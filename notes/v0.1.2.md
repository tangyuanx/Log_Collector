## 启动兼容性与打包

- 固定 Qt、PyInstaller 和 psutil 版本，改用 Windows Server 2022 构建。
- 单文件包不再携带构建机的 ucrtbase.dll 和 APISet 系统 DLL；保留 Python 与应用所需的 VC 运行库。
- 发布前检查实际 EXE 的运行库内容，并从不含 Python 的 PATH、中文 EXE 路径、中文临时目录启动，确认 Qt 窗口打开。
- 新增 LogCollector-Portable.zip 作为无需临时解包的便携目录版。单文件 EXE 仍是主版本。

## 界面

- 参照 cmd_send 当前的白色、中性灰、细边框和紧凑标题栏。
- 中文使用黑体字体回退，英文优先 Times New Roman。
- 使用帮助、检查更新移至顶部；新增与命令工具相同位置的窗口控制。
- 保留拖选具体 MobaXterm 会话、开始、停止保存的操作。

## 使用说明

Windows 10/11 x64。图中的 DLL 加载错误可能有多种原因；以上改动解决打包兼容性隐患，并增加 EXE 启动验证，仍需在报错电脑上确认。如果单文件版仍在临时目录加载 DLL 失败，可使用便携 ZIP：完整解压后运行目录内的 LogCollector.exe，保留 _internal 文件夹。

单文件版支持软件内替换升级。便携目录版可检查版本，但升级时需下载新的完整便携包，解压到新目录运行。

MobaXterm 仍需开启日志输出，自动日志关联仍需真实会话验证。
