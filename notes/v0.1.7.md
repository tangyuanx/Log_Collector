## 进一步改善字体清晰度

- 针对 v0.1.6 字缘偏软、像有灰色阴影的反馈，使用横纵双向像素对齐，减少低像素密度屏幕上的笔画灰边。
- 中文优先采用 Microsoft YaHei UI / Microsoft YaHei 的常规字重，缺失时回退到 SimHei；英文使用 Times New Roman。
- 辅助说明、保存路径、版本号等小字提高至至少 14px，并提高文字对比度。
- 保持灰阶抗锯齿，避免重新引入彩边。

## 验证

- Windows 实际 EXE 在 100%、125%、150% 缩放下检查标题、目标会话、说明、状态和计量五处文字，记录实际字体、字号和像素对齐方式，并导出渲染图片。
- 保留字体缺失、彩边、文字裁切及启动、置顶、采集、升级重启检查。
